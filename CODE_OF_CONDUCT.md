# Código de conducta

Este proyecto recibe contribuciones de personas con distintos niveles de experiencia. Participa con respeto, especialmente cuando haya desacuerdo técnico.

Se espera lenguaje inclusivo, crítica sobre el trabajo y no sobre la persona, reconocimiento de autoría y respeto a la privacidad. No se permite acoso, discriminación, amenazas, contenido sexual no solicitado, doxxing ni publicación de información privada. No se aceptan datasets obtenidos de chats privados o mediante evasión de controles.

Estas reglas aplican a issues, pull requests, revisiones y otros espacios oficiales del repositorio. El mantenedor, @Quiarom, puede editar o retirar contenido, cerrar conversaciones o limitar acceso de forma proporcional; explicará las decisiones cuando sea seguro hacerlo. Un error de buena fe se trata como oportunidad de corregir, no como motivo automático de expulsión.

Para desacuerdos técnicos, abre un issue sin datos personales. Para acoso, amenazas o exposición de datos privados, usa el canal privado de [reporte de abuso de GitHub](https://support.github.com/contact/report-abuse), indicando el repositorio y los enlaces relevantes; no reproduzcas datos sensibles públicamente. Para fallos de seguridad del software, sigue SECURITY.md. No se inventa aquí un correo privado de contacto ni se promete un plazo de respuesta.
