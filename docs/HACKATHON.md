# Contexto de la hackathon 30X

Proyecto preparado para el reto Radar de contenido de [30X Hackathon](https://hackathon.30x.com/). La web del evento indica que el repositorio debe ser público durante la revisión. El proyecto es una propuesta independiente; no es un producto oficial ni implica respaldo de 30X o de sus aliados. No se copian sus logotipos.

El flujo demostrable es: necesidad observada en conversaciones → evidencia → pregunta posiblemente pendiente → novedad externa relacionada → propuesta editorial. La comunidad de la demo es sintética; no se ha analizado Asilo Digital. Los recursos externos reales están separados.

Guion: [DEMO.md](DEMO.md). Reglas: [METRICS.md](METRICS.md). Comprobaciones registradas: [VERIFICATION.json](VERIFICATION.json). Estas comprobaciones locales no deben confundirse con el estado actual de CI, visible en la pestaña Actions.

El nombre actual del repositorio es provisional y está en revisión de marca. La referencia 30X se utiliza para identificar la participación prevista en el evento, no como atribución de propiedad del organizador.
